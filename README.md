# Nowemi — Galerie immersive

Déposez tous les fichiers à la racine du dépôt et activez GitHub Pages sur la branche principale. Aucun build requis. Pour une visite locale, utilisez `python3 -m http.server 8000`.

Sept images fournies, conservées sans retouche. Les titres sont descriptifs et provisoires. Modifiez les titres et descriptions dans app.js. Les techniques, années et dimensions restent à renseigner dans index.html.

Visite libre : glisser pour regarder, ZQSD/WASD ou flèches pour marcher, clic au sol pour avancer. Visite guidée, plan, fiches et agrandissement disponibles.
