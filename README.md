# Nowemi — Loft optimisé

Tous les fichiers sont à la racine. Aucun build ni installation nécessaire.

1. Décompressez cette archive.
2. Déposez tous les fichiers extraits à la racine de votre dépôt GitHub.
3. Dans Settings > Pages, choisissez Deploy from a branch, puis main et / (root).
4. Enregistrez et attendez la publication.

Gardez materials.js, three.module.js et les sept images avec index.html.
Pour tester localement, lancez python3 -m http.server 8000 dans le dossier puis ouvrez http://localhost:8000. Ne lancez pas simplement index.html par double-clic : les modules nécessitent un serveur HTTP.

Cette version contient le loft meublé, les matières, les sept œuvres et les optimisations de rendu. Les titres des œuvres restent descriptifs.
